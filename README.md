Last updated: May 26, 2026

Overview

Underworld Clicker is a free Android game developed by SantosaiDev. We are committed to protecting your privacy.

Data Collection

This app does not collect, store, or transmit any personal information. We do not use analytics, advertising SDKs, or tracking of any kind.

This app contains a single optional link to the developer's Steam game page, shown as a non-intrusive message after certain in-game milestones. Tapping this link will open your device's browser and take you to an external website (store.steampowered.com). No data is transmitted by the app itself when this link appears.
